## Переменные окружения (.env)
JWT_SECRET      — случайная строка 64 символа (node -e "...randomBytes(32)...")
JWT_EXPIRES_IN  — срок жизни токена, например 2h
ADMIN_EMAIL / ADMIN_PASSWORD — администратор, создаётся командой npm run db:init

## Лабораторная 7 — ответы
    Одинаковые ли хэши у двух пользователей с одним паролем и почему:
Нет, хэши разные. Алгоритм bcrypt автоматически добавляет к каждому паролю уникальную случайную «соль» и встраивает её прямо в результирующую строку хэша. Это защищает базу данных от предварительно посчитанных радужных таблиц и позволяет скрывать совпадение паролей у разных пользователей.

    Что вернул сервер на регистрацию с "role": "admin":
Сервер вернул роль user (обычный пользователь). Сервер намеренно игнорирует поле role из тела запроса при регистрации, чтобы предотвратить уязвимость mass assignment (массового присвоения), иначе любой желающий мог бы зарегистрироваться как администратор.

    Почему подделанный на jwt.io токен не прошёл:
Потому что у сервера есть секретный ключ JWT_SECRET, который хранится только в файле .env. При изменении payload-данных на стороннем ресурсе подпись токена нарушается, и метод jwt.verify() на сервере мгновенно распознает подделку, выдав ошибку.

    Что произошло после порчи токена в localStorage:
Токен перестал проходить верификацию на сервере, и при попытке сделать защищённый запрос сервер вернул ошибку 401 Unauthorized. Функция-обёртка apiFetch в клиентском коде перехватила этот статус, автоматически очистила localStorage и перезагрузила страницу (выполнила принудительный выход).

    Почему спрятать кнопку в React недостаточно:
Потому что интерфейс фронтенда легко обойти: злоумышленник может отправить прямой HTTP-запрос (например, через консоль браузера, Postman или cURL) с валидным токеном обычного пользователя. Настоящая защита должна быть реализована на бэкенде с помощью middleware requireAuth и requireRole('admin'), которые проверяют права на каждом защищённом маршруте API.

Да, ИИ использовался для нахождение ошибок и сиправление критических проблем
